# FulmenCalc

Calculadora elétrica para eletricistas e engenheiros de automação.

## Instalar

Baixe o APK na página de [Releases](https://github.com/luxasfill/FulmenCalc/releases) e instale no celular.

Pinagens e Infos Úteis são atualizadas automaticamente pela internet ao abrir o app.

## Funcionalidades

**Calculadoras**
- Lei de Ohm, Potência, Queda de Tensão, Fator de Potência, Curto-Circuito
- Dimensionamento de Condutores (NBR 5410)
- Associação de Resistores e Capacitores
- Divisor de Tensão, LED, Conversor de Unidades

**Tabelas**
- Tabela AWG/mm² e Tabela de Fios
- Código de Cores (resistores, capacitores, indutores)
- Decodificador SMD (3/4 cifras, EIA-96, A11)
- Pinagem de CIs com diagrama interativo
- Infos Úteis (embalagens de componentes)
